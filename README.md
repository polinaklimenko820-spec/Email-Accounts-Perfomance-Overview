# Global Sales Analysis

## Project Overview

This project analyzes global e-commerce sales data to identify key sales patterns, customer behavior, and performance across different markets, product categories, devices, and traffic channels.

The analysis was performed using SQL, Python, and Tableau.

## Tools Used

- Google BigQuery / SQL
- Python
- Pandas
- Matplotlib
- Google Colab
- Tableau Public

## Analysis

The project includes:

- Sales analysis by country and continent
- Sales analysis by product category
- Sales performance by device type
- Traffic channel performance
- Sales dynamics over time
- Registered user analysis
- Pivot table analysis
- Correlation analysis
- Statistical hypothesis testing

## Key Insights

- The Americas generated the highest total sales, with the United States being the leading country.
- Sofas & armchairs generated the highest revenue among product categories.
- Desktop users generated the largest share of sales, followed by mobile users.
- Organic Search was the strongest traffic channel by total sales.
- Sales showed noticeable fluctuations during the analyzed period, with several significant peaks in December and January.

The dataset contains 349,545 sessions covering the period from November 1, 2020 to January 31, 2021.

The data includes information about sessions, geography, devices, traffic sources, registered users, orders, and products.
